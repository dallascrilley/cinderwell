# Matchbox brand

**Formerly:** Cinderwell  
**Mark:** Isometric charcoal matchbox mid-strike with coral flame  
**Vibe:** Playful, disposable by design — light it, burn through, prove it's gone  
**Tagline:** Disposable cloud servers with a lease.

## Naming

- Product name: **Matchbox**
- Pitch: Disposable cloud dev servers with a built-in expiration date.
- Language: spin up a Matchbox, Matchbox lease, Matchbox expired, Matchbox receipt.
- Repo may still be `cinderwell` until a rename; user-facing copy should say Matchbox.
- Avoid "cinderwell" in new marketing copy except a brief formerly note / migration.

## Do / don't

- **Do** keep the strike action visible (ignition = spin-up).
- **Do** stay charcoal + coral.
- **Don't** imply the box lasts forever — expiry / lease is the product.
- **Don't** skip the proof story: teardown produces a receipt.
